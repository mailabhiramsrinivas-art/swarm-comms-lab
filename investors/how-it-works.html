How it works

How it works

Every drone runs identical software. Each one decides for itself how to behave, based only on what it can hear right now. There is no single point that, once lost, stops the swarm.

Each drone asks itself two questions

Many times a second, every drone checks what it can hear and picks its mode. As soon as the radio allows, it moves back up to a better mode.

When the leader is lost, a drone takes over in about a second

The ground station leads whenever drones can hear it. If it goes silent, the swarm replaces it on its own, without a vote.

Five design choices that keep it robust

No fixed roles

Any drone can lead. The leader is simply the lowest-numbered one in contact, with the ground station always first in line.

No voting

Every drone applies the same rule to the same information, so they agree without sending extra messages.

Share what you see

Drones pass on raw sightings, not opinions, so every drone builds the same picture of the sky.

Act first, fix later

A drone commits to a target straight away. Two drones briefly chasing one threat costs less than everyone hesitating.

Flying stays on board

Each drone steers itself. The radio carries only decisions, so a lost message costs time, never control of the drone.

For technical readersAlgorithms, messages and timings

Assignment

The leader computes a globally optimal drone-to-threat assignment with the Hungarian algorithm and broadcasts it as a PLAN at 5 Hz. Without a plan, drones send CLAIMs with a cost; the lowest cost wins and ties go to the lower ID, so every drone resolves conflicts identically without another round of messages.

Leader election

The coordinator is the lowest ID heard recently. The ground station is ID 0. When it is silent past the leader timeout (1.0 s) the next lowest ID takes over; when a lower ID reappears, the stand-in steps down.

Every message carries origin, sequence number, timestamp and hop limit (a 9-byte header) and is relayed by flooding up to 3 hops (claims at most 2). Timeouts: plan 0.6 s, contact 0.6 s, leader 1.0 s. Every setting can be changed in the engineering simulator.
